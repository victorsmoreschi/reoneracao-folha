# Paper

LaTeX source of the paper and the slides, exported from Overleaf.

- `main.tex`: paper source (bibliography is inline, no `.bib` needed).
- `main.pdf`: compiled final version of the paper.
- `apresentacao_cgs_sat_main.tex`: Beamer slides.
- `figuras/`: all figures used by the paper and slides, as they are in the Overleaf project.

To compile, upload this folder to Overleaf or run `latexmk -pdf main.tex` from inside `paper/` (pdfLaTeX).
